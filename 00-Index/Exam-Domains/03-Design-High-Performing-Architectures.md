# Domain 3: Design High-Performing Architectures (24%)

Source: official AWS SAA-C03 exam guide.

## Task 3.1: Determine high-performing and/or scalable storage solutions

**Knowledge of:** Hybrid storage solutions; storage services (S3, EFS, EBS); storage types (object/file/block).

**Skills in:** Determining storage services/configurations that meet performance demands; determining storage services that scale for future needs.

**Covered by:** [[03-Storage/01-S3]] · [[03-Storage/02-S3-Advanced]] · [[02-Compute-EC2/03-EC2-Instance-Storage]] · [[03-Storage/04-Storage-Extras]]

## Task 3.2: Design high-performing and elastic compute solutions

**Knowledge of:** AWS compute services (Batch, EMR, Fargate); distributed computing concepts; queuing/messaging; scalability (EC2 Auto Scaling, AWS Auto Scaling); serverless technologies; container orchestration (ECS, EKS).

**Skills in:** Decoupling workloads to scale independently; identifying metrics/conditions for scaling actions; selecting compute options/features (instance types); selecting resource type/size (Lambda memory).

**Covered by:** [[02-Compute-EC2/01-EC2-Basics]] · [[02-Compute-EC2/02-EC2-Associate]] · [[02-Compute-EC2/04-High-Availability-Scalability]] · [[06-Containers-Serverless/01-Containers]]

## Task 3.3: Determine high-performing database solutions

**Knowledge of:** AWS global infrastructure; caching strategies (ElastiCache); data access patterns (read vs write intensive); database capacity planning; database connections/proxies; database engines; database replication (read replicas); database types (serverless, relational vs non-relational, in-memory).

**Skills in:** Configuring read replicas; designing database architectures; determining appropriate database engine/type; integrating caching.

**Covered by:** [[04-Databases/01-RDS-Aurora-ElastiCache]] · [[04-Databases/02-Databases-Overview]]

## Task 3.4: Determine high-performing and/or scalable network architectures

**Knowledge of:** Edge networking (CloudFront, Global Accelerator); network architecture design (subnet tiers, routing, IP addressing); load balancing; network connection options (VPN, Direct Connect, PrivateLink).

**Skills in:** Creating network topology (global, hybrid, multi-tier); determining scalable network configurations; determining appropriate resource placement; selecting load balancing strategy.

**Covered by:** [[05-Networking-Content-Delivery/02-VPC]] · [[05-Networking-Content-Delivery/03-CloudFront-Global-Accelerator]]

## Task 3.5: Determine high-performing data ingestion and transformation solutions

**Knowledge of:** Data analytics/visualization services (Athena, Lake Formation); data ingestion patterns; data transfer services (DataSync, Storage Gateway); data transformation services (Glue); secure access to ingestion access points; streaming data services (Kinesis).

**Skills in:** Building/securing data lakes; designing data streaming architectures; designing data transfer solutions; implementing visualization strategies; selecting compute for data processing (EMR); selecting ingestion configurations; transforming data between formats.

**Covered by:** [[04-Databases/03-Data-Analytics]] · [[03-Storage/04-Storage-Extras]]
