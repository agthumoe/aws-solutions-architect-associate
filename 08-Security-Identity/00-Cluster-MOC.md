# Security & Identity

Covers advanced identity and access management beyond the IAM basics — multi-account governance with AWS Organizations and SCPs, IAM Identity Center (SSO), Directory Service, and Control Tower — plus the core data-protection and threat-detection services (KMS, Secrets Manager, SSM Parameter Store, ACM, CloudHSM, WAF, Shield, Firewall Manager, GuardDuty, Inspector, Macie). This cluster is central to **Domain 1: Design Secure Architectures**, the highest-weighted domain on the exam (30%).
