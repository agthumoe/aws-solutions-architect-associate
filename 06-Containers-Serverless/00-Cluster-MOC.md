# Containers & Serverless

Covers containerizing and running applications on AWS without managing servers: Docker/ECS/EKS/Fargate, the core serverless building blocks (Lambda, DynamoDB, API Gateway, Cognito), and worked serverless architecture case studies that combine them.

## Notes
- [[01-Containers]] — Docker fundamentals, Amazon ECS (EC2 & Fargate launch types), Amazon ECR, and Amazon EKS, including IAM roles, load balancing, data volumes, and auto scaling for containers.
- [[02-Serverless-Overview]] — AWS Lambda (pricing, limits, concurrency, cold starts, edge functions), Amazon DynamoDB (capacity modes, DAX, streams, global tables), API Gateway, Step Functions, and Amazon Cognito (User Pools vs. Identity Pools).
- [[03-Serverless-Architectures]] — Four worked case studies (serverless mobile app, serverless hosted website, microservices, and CloudFront-fronted software distribution) showing how the container/serverless building blocks combine into full architectures.
