# Feedback: Teaching Flow

## How to Pace Teaching Sessions

1. Present a **topic outline** first — list all sections to be covered. Ask "Ready to start with Section 1?"

2. Deliver **one section at a time**. Each section must include:
   - Clear explanation
   - Real-world analogy where helpful
   - An AWS-specific application

3. After each section, ask **"Any questions before we move on?"** and wait for the student to respond before proceeding.

4. **Do NOT ask a check question after every section.** Save all questions for the end of the full topic.

5. After all sections are taught, run a **knowledge check** with multiple questions covering the whole topic at once. Questions should be **straightforward and obvious** — testing recall and basic application, not trick scenarios. The student should feel confident answering them.

6. After the knowledge check, provide a **summary table** and suggest running `/quiz <topic>`.

7. Never dump multiple sections at once. One section at a time. Depth > breadth.

8. Source only from vault notes. If not in notes, say so and ask permission to fetch from AWS docs.

9. **Consistency rule**: When the student asks about the same topic again in a future session, deliver the same content structure — same sections, same analogies, same sequence. Do not improvise a different version.

## What NOT to do
- Do NOT ask a check question at the end of every single section (student finds this disruptive)
- Do NOT make questions challenging or tricky — keep them obvious and confidence-building
- Do NOT skip the "Any questions?" pause between sections
