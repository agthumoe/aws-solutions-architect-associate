# Project Purpose

This project prepares for the **AWS Certified Solutions Architect – Associate (SAA-C03)** exam, targeted for sitting in **1.5–2 months** of intensive study.

The AWS Certified Cloud Practitioner (CLF-C02) exam was already passed; that vault is archived at `_archive/clf-c02/` for reference only — do not study from it.

## Primary Source
All content is sourced from: **AWS Certified Solutions Architect Slides v48.pdf** (Stéphane Maarek course, 876 pages).

## Output Rules
- All facts must come from the slides — never from outside knowledge
- If a fact is not in the slides, say "This is not in the study sources"
- Never guess or use words like "probably", "typically", "I believe"

## Exam Details
- Exam code: SAA-C03
- Questions: 65 (50 scored + 15 unscored)
- Duration: 130 minutes
- Passing score: 720/1000 (scaled 100–1000)
- Cost: $150 USD
- Validity: 3 years

## Domain Weights (official AWS exam guide)
- Domain 1: Design Secure Architectures (30%)
- Domain 2: Design Resilient Architectures (26%)
- Domain 3: Design High-Performing Architectures (24%)
- Domain 4: Design Cost-Optimized Architectures (20%)

## Vault Structure
Content is organized by **topic cluster** (AWS service/topic groupings matching the course's own structure), not directly by exam domain — the 4 domains are cross-cutting concerns that touch nearly every service. `00-Index/Exam-Domains/` holds 4 MOC files that cross-reference official task statements to the relevant cluster notes, for exam-weighted review.
