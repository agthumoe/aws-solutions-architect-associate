# Today's Study Plan

Generate a focused study plan for today's session.

**Usage:** `/today`

## Instructions

1. Read the progress tracker: `memory/progress_tracking.md`

2. Identify today's priority:
   - Any domain marked 🟠 Needs Review → review that first
   - Any recorded weak areas → address those
   - Otherwise → highest-weight unstarted or in-progress domain

3. Present a **3-block study plan** (morning / afternoon / evening or Block 1 / 2 / 3 if no time is given):

   **Block 1 (~45 min):** Active reading
   - Specific note files to read (with paths)
   - Key things to look for while reading

   **Block 2 (~30 min):** Practice
   - Specific `/quiz` command to run
   - Target score to hit

   **Block 3 (~15 min):** Review & record
   - `/misconceptions <topic>` to check understanding
   - Update the progress tracker

4. End with: "After today's session, run `/progress` to update your tracker."

## Constraints
- One topic cluster focus per day (depth > breadth)
- Always include at least one quiz block
- Domain 1 - Design Secure Architectures (30%) gets priority over others if all statuses are equal
