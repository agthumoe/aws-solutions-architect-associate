# Topic Summary

Generate a concise exam-focused summary of any topic.

**Usage:** `/summary <topic>`  
**Examples:** `/summary domain2`, `/summary prompt-engineering`, `/summary amazon-bedrock`

## Instructions

Given `$ARGUMENTS` as the topic:

1. Read the relevant vault note(s).

2. Produce a **structured summary** with these sections:

   ### What This Topic Is
   2–3 sentences maximum.

   ### Key Concepts (exam-critical only)
   Bulleted list — max 8 items. If you can't fit it in 8 bullets, you're being too detailed.

   ### AWS Services Involved
   Table: Service | Role in this topic

   ### The 3 Things the Exam Tests Here
   Specifically what question patterns appear for this topic.

   ### Memory Hooks
   1–2 memorable phrases that lock in the key distinctions.

3. Keep the whole summary to one screen. This is a final-review tool, not a teaching tool.
