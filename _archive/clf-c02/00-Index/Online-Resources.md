## Key Domain Coverage in Official Exam Guide

### Domain 1: Cloud Concepts (24%)
- Task 1.1: Explain benefits of AWS Cloud
- Task 1.2: Identify design principles of AWS Cloud
- Task 1.3: Understand benefits and strategies of cloud migration (CAF, 7 Rs)
- Task 1.4: Understand concepts of cloud economics (fixed vs variable costs, rightsizing, BYOL)

### Domain 2: Security and Compliance (30%)
- Task 2.1: Shared responsibility model
- Task 2.2: AWS security, governance, and compliance concepts
- Task 2.3: Access management capabilities (IAM, Organizations, SCPs)
- Task 2.4: Identify components for securing AWS resources (WAF, Shield, GuardDuty, Macie, Inspector)

### Domain 3: Cloud Technology and Services (34%)
- Task 3.1: Methods of deploying and operating in AWS Cloud
- Task 3.2: AWS global infrastructure
- Task 3.3: AWS compute services
- Task 3.4: AWS database services
- Task 3.5: AWS network services
- Task 3.6: AWS storage services
- Task 3.7: AWS AI and ML services and analytics services
- Task 3.8: Scope of other AWS services categories (IoT, EUC, business apps, frontend/mobile)

### Domain 4: Billing, Pricing, and Support (12%)
- Task 4.1: AWS pricing models
- Task 4.2: Billing, budgets, and cost management
- Task 4.3: AWS technical resources and support options

## Tips for Using These Resources

1. **Use official exam guide Task Statements** as a checklist — each task statement is directly testable
2. **AWS FAQ pages** often contain exact language that appears in exam questions
3. **Tutorials Dojo** practice exams are harder than the real exam — scoring 75%+ there predicts passing
4. **Skill Builder's official practice exam** (6 questions, free) gives you real exam question style
5. **In-scope services list** is the definitive list — if a service isn't on it, it won't be tested
